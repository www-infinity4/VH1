# VH1

Synchronized nonstop music-video channel using five-minute programming slots.

- 288 five-minute slots per viewer-local day
- music video plays first; unused slot time becomes **Intermission** reserved for the future advertising layer
- same schedule survives refresh during the day
- new daily order at local midnight
- new weekly shuffle seed so the next week receives a different rotation
- separate VH1 catalog and seed from MTV
- YouTube embed failures are skipped automatically
- videos longer than the five-minute slot are rejected so the channel does not cut a music video in half
